Overview

What this project is about

Shannon entropy measures the average uncertainty of a probability distribution. Huffman coding turns the same probabilities into efficient variable-length binary codes.

From probability to code length

Rare outcomes carry more information than common ones. Entropy combines the information of all outcomes into one average value measured in bits.

Huffman coding uses the probabilities to build a binary tree. Frequent symbols receive shorter paths, while rare symbols receive longer paths.

Main formula H(X) = -Σ pᵢ log₂(pᵢ)

Part 01

Self-Information

Self-information measures how surprising one outcome is.

Information of one event

An outcome with probability 1 is completely predictable and carries 0 bits of new information. A less probable outcome carries more information.

I(xᵢ) = log₂(1 / pᵢ) = -log₂(pᵢ)
Example

Probability 1/8

An event with probability 0.125 carries three bits of self-information.

I = log₂(8) = 3 bits

Part 02

Shannon Entropy

Entropy is the probability-weighted average of the self-information values.

Minimum and maximum

Entropy is 0 when one outcome has probability 1. For n possible outcomes, entropy is largest when all probabilities are equal.

The maximum possible value is log₂(n). A distribution close to this maximum is highly uncertain; a distribution close to 0 is highly predictable.

Maximum entropy Hmax = log₂(n)
Predictable 1, 0, 0, 0 H = 0 bits
Unequal 0.5, 0.25, 0.125, 0.125 H = 1.75 bits
Uniform 0.25, 0.25, 0.25, 0.25 H = 2 bits

How Huffman coding works

The two least probable nodes are repeatedly joined. Each left branch receives 0 and each right branch receives 1.

H(X) ≤ L̄ < H(X) + 1
Course example

0.5, 0.25, 0.125, 0.125

One valid set of Huffman codes is 0, 10, 110 and 111. The average code length is 1.75 bits.

1×0.5 + 2×0.25 + 3×0.125 + 3×0.125 = 1.75

Important note

Equal probabilities

Several different Huffman trees may be equally correct when probabilities are tied. This page uses a stable input order so the result stays predictable.

Character model

Each character is treated as a possible outcome. Its frequency determines its probability and its Huffman code length.

p(character) = count / total characters
Interpretation

Bits per character

Text entropy estimates the average information in one character. Huffman length shows the average number of actual binary digits used by this code.

Compression note

Tree metadata is not free

The displayed compressed size counts encoded text bits only. A real file must also store or transmit the code tree, alphabet and other metadata.
