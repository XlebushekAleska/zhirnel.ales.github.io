Overview

What this project is about

The page connects basic probability with the main counting formulas used in elementary combinatorics.

Main idea

Many probability problems can be solved by counting all possible outcomes and then counting only the favorable outcomes.

Every calculator below shows not only the final value, but also the substituted formula and the intermediate arithmetic used to obtain it.

Basic probability P(A) = favorable outcomes / all outcomes

Part 01

Probability Calculator

Probability as a ratio between favorable outcomes and all equally likely outcomes.

Theory

If all outcomes are equally likely, the probability of an event is the number of favorable outcomes divided by the total number of possible outcomes.

P(A) = |A| / |Ω|
Example

Two dice

Two distinguishable dice produce 36 ordered outcomes. The sum 9 occurs in four of them: (3,6), (4,5), (5,4), (6,3).

P(sum = 9) = 4 / 36 = 1 / 9 ≈ 11.11%

Part 02

Permutations and Factorial

Permutations count arrangements when order matters. For n different objects, their number is n factorial.

Why factorial appears

There are n choices for the first position, n − 1 for the second, n − 2 for the third, and so on until only one choice remains. Multiplying these numbers produces the factorial.

Pₙ = n! = n × (n − 1) × ... × 2 × 1

By definition, 0! = 1. Factorial is therefore not a separate counting problem here: it is the operation used to calculate the number of permutations.

Example

GALOIS

All six letters are different, so every ordering is a different permutation.

6! = 6 × 5 × 4 × 3 × 2 × 1 = 720

Part 03

Permutations with Repeated Objects

Repeated identical objects reduce the number of distinct arrangements.

Theory

Start with n! arrangements as if every object were different. If one object occurs m times, those m copies can be permuted among themselves in m! indistinguishable ways, so we divide by m!. The same is done for every repeated group.

N = n! / (m₁! × m₂! × ... × mᵣ!)
Example

ABBA

The word has four letters. A occurs twice and B occurs twice.

4! / (2! × 2!) = 24 / (2 × 2) = 6

Part 04

Binomial Coefficient and Pascal's Triangle

The binomial coefficient counts unordered selections and appears directly as an entry of Pascal's triangle.

Combinations

When order does not matter, choosing k objects from n distinct objects gives the binomial coefficient “n choose k”.

C(n,k) = n! / (k! × (n − k)!)

Row n of Pascal's triangle contains the coefficients C(n,0), C(n,1), ..., C(n,n). Every interior value is the sum of the two values diagonally above it.

C(n,k) = C(n − 1,k − 1) + C(n − 1,k)

Part 05

Team Selection

Team selection is a direct application of the binomial coefficient.

Theory

If N players are available and exactly M must be chosen, the order in which they are selected is irrelevant. Therefore the answer is C(N,M).

Teams = C(N,M) = N! / (M! × (N − M)!)
Example

Choose 4 from 10

C(10,4) = 10! / (4! × 6!) = 210

Part 06

GALOIS-style Arrangement Probability

A word-arrangement example that combines permutations, combinations and probability.

Problem idea

The classical word GALOIS contains three vowels and three consonants. We ask for the probability that every vowel appears before every consonant in a random permutation.

P = (V! × C!) / (V + C)! = 1 / C(V + C,V)
GALOIS

Three vowels and three consonants

P = (3! × 3!) / 6! = 36 / 720 = 1 / 20 = 5%
