Overview

What this project is about

This page explains basic counting methods used in probability theory and combinatorics.

Main idea

Many probability problems can be solved by counting all possible outcomes and then counting only the favorable outcomes.

The project combines short theoretical explanations with interactive calculators. All calculations are performed directly in the browser using JavaScript.

Basic probability P(A) = favorable outcomes / all outcomes

Part 01

Probability Calculator

Probability as a ratio between favorable outcomes and all possible outcomes.

Theory

If all outcomes are equally likely, the probability of an event is calculated as the number of favorable outcomes divided by the number of all outcomes.

P(A) = |A| / |Ω|
Example

Two dice

If two distinguishable dice are rolled, there are 36 possible outcomes. The sum 9 appears in 4 outcomes: (3,6), (4,5), (5,4), (6,3).

P(sum = 9) = 4 / 36 = 1 / 9 ≈ 11.11%

Part 02

Factorial

Factorial is used to count the number of possible arrangements of different objects.

Theory

The factorial of a non-negative integer n is the product of all positive integers from 1 to n. By definition, 0! is equal to 1.

n! = 1 × 2 × 3 × ... × n
Example

Six different letters

The word GALOIS has six different letters, so the number of all possible arrangements is 6!.

6! = 720

Part 03

Permutations

Permutations count the number of ways to arrange different objects when order matters.

Theory

If all objects are distinguishable, the number of possible arrangements is equal to n factorial.

Permutations = n!
Example

GALOIS

Because all six letters in GALOIS are different, each arrangement is counted separately.

Total arrangements = 6! = 720

Part 04

Repeated Objects

If some objects are identical, repeated arrangements should not be counted several times.

Theory

When a word or a set contains repeated elements, the total number of different arrangements is reduced because identical objects cannot be distinguished.

n! / (m₁! × m₂! × ... × mₖ!)
Example

ABBA

The word ABBA has 4 letters. A appears 2 times and B appears 2 times.

4! / (2! × 2!) = 6

Part 05

Binomial Coefficient

The binomial coefficient counts the number of ways to choose k objects from n objects.

Theory

Combinations are used when order does not matter. The binomial coefficient is one of the most important counting formulas.

C(n, k) = n! / (k! × (n - k)!)
Example

Choosing 3 objects from 5

The coefficient C(5, 3) shows how many different groups of 3 objects can be selected from 5 objects.

C(5, 3) = 10

Part 06

Team Selection

Selecting a team from a group is a practical example of combinations.

Theory

If there are N players and we need to select M of them, the number of possible teams is C(N, M).

Teams = C(N, M)
Example

Football team

Selecting M players from N available players can be represented as marking selected players and unselected players.

Number of teams = C(N, M)

Part 07

GALOIS Example

Example based on arranging the letters of the word GALOIS.

Problem idea

The word GALOIS contains six different letters. The task is to count the probability that all vowels appear before all consonants in a random arrangement.

P = (3! × 3!) / 6! = 1 / 20
Example

Vowels before consonants

The vowels A, O, I can be arranged in 3! ways. The consonants G, L, S can also be arranged in 3! ways. The total number of arrangements is 6!.

Good arrangements = 3! × 3!, total arrangements = 6!

Word arrangement calculator

The default example is GALOIS, but you can enter another word. The calculator finds the probability that all vowels appear before all consonants.
